SplitPro

A conversational, AI-powered bill-splitting app. You paste a receipt or snap a photo of one, chat naturally about who had what, and SplitPro's agent figures out the minimal set of payments to settle up.

What it does

  • Conversational parsing — paste bill text or describe it in chat; the agent extracts line items, tax, and tip.
  • Receipt photo upload — a vision model reads a receipt image and hands the extracted text back into the same chat flow.
  • Item-level assignment — assign items to one or more people, including fractional/quantity-based splits ("Alice had 1 of 4 burgers").
  • Multi-bill sessions — add several bills to one session; everything settles together.
  • Minimal settlements — a greedy debt-simplification algorithm reduces the group's debts to the fewest possible payments.
  • Accounts & history — Google sign-in, and every session is persisted to SQLite so chat history survives a server restart.
  • CLI mode — the same agent runs standalone in a terminal, no server or auth required.

How the pieces fit

Request flow: browser → FastAPI → per-session ChatAgent → LLM provider, with SQLite as the write-through store.
